## 1. What makes a strong README file for an R project?

A strong README explains the purpose of a project and helps another person understand
how to use it. It should include a clear title, overview, objectives, folder structure,
dataset description, dependencies, installation instructions, example usage, expected
outputs, and limitations. Headings, short paragraphs, bullet points, tables, and code
blocks make information easier to scan. In this project, the README describes the
synthetic retail dataset, explains how to install the required package, and shows how
to run the R script. A clear README makes a project easier to understand, maintain,
and share.

## 3. What are the limitations and ethical considerations of using AI for documentation?

AI can produce professional-sounding text that includes inaccurate assumptions,
incorrect paths, or instructions that do not match the actual project. It may also
overlook assignment requirements. AI should support writing and organization rather
than replace testing, calculations, or personal understanding. Ethical use includes
disclosing the AI tool, model, date, and prompts; editing and validating the output;
and taking responsibility for the final submission. Privacy is important, so this
project uses synthetic data and contains no personal or confidential information.
